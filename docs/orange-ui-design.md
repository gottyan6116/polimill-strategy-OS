# オレンジテーマ・共通ダイアログ（2026-10-21）

ユーザーは経営サマリー刷新に加えて今回のUI改修と本番公開まで承認済み。最後の指定であるFBB03B→FF6B1Aのサイドバー、白文字700を採用。データ・計算・API・DB・認証は変更しない。

全ての見た目の値を:rootへ移し、共通theme.cssで面、カード、ボタン、表、タイポグラフィを定義する。以前のサイドバーの色指定は削除する。旧来の各パネルCSSの色/角丸/影も変数参照にし、ティール値を残さない。業務データとして保存済みの色は移行せず、描画側のパレットでテーマを適用する。

共通.dialogを全10ダイアログに適用。useDialogは表示・終了アニメーション、Esc、暗幕、フォーカス復帰を担当し、保存処理は既存のまま。保存中はユーザーの誤終了を防ぎ、保存成功による終了は許可する。reduced-motionでは即時終了。

組織はauto-fit/minmax240pxで折り返し、横スクロールを廃止。一列に収まったときだけ全社→部門の接続線を表示。目標リンクはカード内部へ移し、開閉ボタンは詳細操作と分離する。未設定のKPIのボタンは既存ObservationEditorを対象KPI/月/予算に事前選択して開く。部門は既存目標編集へ。

全社目標の保存機能は存在しない。新規データ機能を作らないという指定に従い、全社目標設定ボタンは登録状況の確認と既存部門目標への導線までとする。この制約はユーザーへ事前に説明済みで、ダイアログにも保存未接続と表示する。

検証: 38単体、全既存回帰＋中央配置/開閉/焦点/配色/折り返しの新規E2E、1370/1920/390pxで全5ページと全財務タブを撮影。ソースの色・角丸・影の残存検索、型チェック、Workerビルド、独立レビュー、GitHub CIを経てmainへ統合して公開し、本番で再確認する。

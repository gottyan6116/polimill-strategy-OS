# 可読性と組織ツリー（2026-10-21）

既存ツリーの feature/organization-strategy-tree とPR #1を継続する。本番は変更せず、ユーザー承認後に公開する。既存認証・API・DB・ルート・数値ロジックを保持。

原因: body 14pxに加え、画面個別の9〜11px指定とSVG viewBoxの縮小表示。zoom/scaleによる全体縮小はなく、Tailwind小サイズutilityの多用もない。小サイズのCSS指定を共有トークンへ移し、タイトル28、セクション20、カード16、本文14、ナビ15、操作14、補足12pxを下限とする。SVGは14pxの文字と最小キャンバス幅を持ち、必要な箇所だけ内部スクロールする。ページの最大幅制限を外し、行高・カード寸法・余白を文字サイズに合わせる。

色と日本語フォントは既存トークンを再利用。白/灰/ティールの階層表現を維持し、PCは全社目標→4部門の横列→目標→KPIのトップダウン。部門詳細・施策詳細・一覧の状態保持を再利用し、値や進捗は捏造しない。

検証: 改修前後の1440px/deviceScaleFactor1の全主要画面、1920px、390px、全テキスト下限/操作14px/ページはみ出し、既存回帰、型、単体、本番Workerビルド。参照デザイン画像は今回も添付されていないため、画像との一致は未確認。文章要件との比較を行う。

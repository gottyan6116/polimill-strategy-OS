# 経営会議用の設定とデータ契約

## 既存数値の保全

`0005_management_reporting.sql` は既存の数値・自己申告進捗を変更せず、実績観測値を `management_values` に複製します。旧編集APIとの互換性は保持し、実績が変更されると観測値も同期します。変更された実績は未締めへ戻します。NOPAT・ROIC・FCF等の既存計算本体は変更していません。

観測値キーは `entity_type + entity_id + metric + scenario + period`。`scenario` は `actual / budget / forecast / prior_year`、金額の保存単位は百万円（1円精度）です。`value:null` と数値0は別です。予算差・前年比の分母が0なら率は「—」、観測値がない場合は「未設定」。年度は例 `2026`、月は例 `2027-03`。旧KPI現在値だけは対象月不明のため `current` に保全し、月次計画比較には日付付き履歴の実績を使います。

旧データには予算・見込み・月別計画・締め情報がありません。ユーザー指定によりすべて未設定のまま移行します。年度見込みを未締め実績で埋めたり、年目標を月割りしたりしません。月次グラフも未締め月の見込みがなければ棒を描画しません。仮実績は合計と明細で確認できます。

前年比較は同じ事業・項目の明示された `prior_year` 観測値を優先し、観測値自体が未登録の項目だけ既存の前年度実績を参照します。明示的なnullは未設定になります。事業が一つでも不足すると全社比較は未設定です。予算・見込みも一部の事業だけで全社合計を作りません。

## 設定の入口

- `config/management.ts`: KPIの定義、責任者、方向、判定閾値、`monthlyPlan`、財務ドライバーへのリンク、期限超過警告閾値、既定年度。
- `config/presentation.ts`: 金額・率の桁数、単位、財務系列色、事業系列色、ポートフォリオの基準値・ラベル。
- `config/metrics.ts`: 財務指標の説明・計算定義の表示文。
- `config/reporting.ts` / `config/expense-categories.ts`: 項目名、区分名、費用区分。
- `app/design-tokens.css`: 面・文字・罫線・アクセント・状態色。

例：`kpiConfig['kpi-partners'].monthlyPlan['2027-03']` に会社で定義した対象月計画値を設定します。目標年額から推定しません。KPIの月次値が期末時点残高なのか当月フローなのかは指標定義で明示し、計画も同じ集計方法で登録してください。

画面の「予算・見込み・締め情報を編集」から年度・月・KPIの観測値を保存できます。KPIの対象月予算は月別計画の補完に使用し、設定ファイルに同月の明示指定があればそちらが優先します。APIは `PATCH /api/management`。数値は指標ごとの範囲を検証し、実績数値を変える場合は従来の実績編集を使用します。対象月履歴に実績がないKPIは未判定です。

`is_closed` は締めの事実を表すメタデータです。月の集計は全事業・対象8項目の締めが揃った場合のみ締め済み。何月まで締め済みかは4月から連続した月だけを表示します。年度実績は全事業の16入力項目が締め済みになった場合にラベルを切り替えます。マイグレーション実行日時は元データの発生日ではなく、出典・更新日時とあわせて判断してください。

## マイルストーン・責任・経営への接続

施策進捗は `management_milestones` の完了件数 ÷ 全件数。予定日と実際の完了日を登録し、未設定なら進捗も未設定です。未来の完了日は拒否します。旧自己申告の値は保存記録としてだけ残し、新しい進捗には使いません。期限を過ぎた未完了マイルストーンは例外へ表示します。

請求明細の責任者は追加した `owner` で管理します。未設定は未設定と表示し、期日超過残高が `overdueWarningMillion` を超えると赤で警告します。銀行連携・自動仕訳はありません。

KPI→売上/コスト要因→営業利益→ROICの接続は構造として表示します。因果・単価が未確認のリンクに金額効果を作りません。会社で確認した対応に設定を変更してください。ポートフォリオの初期基準0%は「未設定・参考値」でありWACCを仮定していません。
